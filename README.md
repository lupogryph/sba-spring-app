# SBA Spring App

Sample springboot application used as a client for a spring admin server

JDK 21

Uses :
- spring-boot-starter-web > to enable REST HTTP
- spring-boot-starter-actuator > the actuator lib for app admin features & configuration
- spring-boot-admin-starter-client > enable configuration for Restful communication with the sba server
- spring-boot-starter-quartz > to view the scheduled admin panel in SBA
